# Sumadhura Foods 🌾

> **Pure, Fresh & Traditional Food Ecommerce Platform**  
> *Inspired by Country Delight purity assurance and Swiggy mobile app navigation.*

Live Website: [https://suadhura-foods.vercel.app](https://suadhura-foods.vercel.app)

---

## 🌟 Overview

**Sumadhura Foods** is a modern, high-performance food ecommerce web application designed to bring authentic generational recipes, stone-ground flours, pure desi cow ghee sweets, and sun-dried pickles directly to customers' doorsteps with guaranteed morning 7:00 AM delivery.

---

## 📱 Mobile Experience (Swiggy App Style)

- **Swiggy-Style Location Header**: Quick area selector (`📍 Jubilee Hills, Hyderabad ▾`) and user account circle.
- **Prominent Search Bar**: Direct instant search for pickles, sweets, spices, and flours.
- **Dynamic Offer Carousel**: Interactive promotional food cards with discounts and 1-tap ordering.
- **"What's on your mind?"**: Horizontal circular category rail for quick 1-tap food exploration.
- **Swiggy Delivery Badges**: `⚡ 7 AM Delivery` badges on all product cards with interactive `ADD` / quantity steppers.
- **Floating Cart Pill**: Slides up automatically when items are added (`🛍️ Qty | Total • View Cart ➔`).
- **Fixed Bottom Navigation**: Native app-style tabs (`Sumadhura`, `Explore`, `Cart`, `Orders`, `Account`).

---

## 💻 Desktop Experience (Country Delight Style)

- **Clean White, Grey & Black Theme**: Minimal, premium, and distraction-free aesthetic.
- **Purity Guarantee Bar**: Highlighting 50+ lab tests, morning delivery, and zero palm oil policies.
- **16 Rich Food Categories**:
  - Snacks, Sweets, Pickles, Spices, Masalas, Rice Products, Flours, Dry Fruits, Namkeen, Ready-to-Eat, Ready-to-Cook, Beverages, Bakery Items, Traditional Foods, Healthy Foods, Combo Packs.
- **Interactive Cart & Drawer**: Free delivery progress goal (₹499 threshold), promo coupons (`SUMADHURA10`), and real-time subtotal calculations.
- **Product Details Modal**: Pack size/weight selectors (250g, 500g, 1kg), nutritional breakdown, storage instructions, and related products.
- **Customer Profile & Orders**: Live order tracking with statuses (*Confirmed*, *Delivered*), address manager, and 1-click reorder.
- **Our Services**: Online Food Shopping, Fresh Food Products, Home Delivery, Bulk Orders (with wholesale quote form), Combo Packs, and Customer Support.

---

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: AOS (Animate On Scroll)
- **Deployment**: Vercel

---

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/harishkittuprojects/suadhura-foods.git

# Enter directory
cd suadhura-foods

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` (or the port specified in terminal) to view the application.
